  dev.to — Artikel-Intro

  Title: I wrote a game collection manager for the Commodore 64 in BASIC V2

  ▎ In 2026, I built a game collection manager — not as a web app, not as a mobile app, but as a Commodore 64 BASIC V2 program.
  ▎
  ▎ Here's why, and what I learned.
  ▎
  ▎ The idea
  ▎ I collect retro games. Most collector tools run on modern hardware, but I wanted something that feels right: catalog your C64 games on a C64. No cloud, no app, just a 1541
  ▎ floppy drive and some BASIC.
  ▎
  ▎ What it does
  ▎ RETROKAUZ manages up to 100 entries with title, studio, year, system, medium and rating. It sorts alphabetically on save (bubble-sort — because that's what you do in BASIC),
  ▎ filters by any field, and backs up automatically to a .bak file on disk.
  ▎
  ▎ The constraints were the fun part
  ▎ No arrays of objects. No functions. No imports. Every subroutine lives at a fixed line number. Memory is tight. GOTO is your best friend whether you like it or not.
  ▎
  ▎ The full source code is on GitHub (GPL v3), including a ready-to-run .D64 image:
  ▎ 👉 https://github.com/it-dennis/retrokauz-game-collector-fuer-c64
